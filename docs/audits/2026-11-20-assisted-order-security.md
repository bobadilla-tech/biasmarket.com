## Criteria outside this backend test run

- The public-page privacy notice is a UI criterion and was not inspected in this
  backend-only task.
- “No marketing” is a product/data-use policy; code tests cannot establish
  organizational practice. Current assisted-order creation tests verify no
  buyer account, email, or cross-store history is created/exposed by the flow.
- Live Sentry/GlitchTip and Caddy settings, deployed rate-limit configuration,
  backups/log retention, and pilot behavior require environment-level checks.
- #279 asks for this audit to be linked from the project wiki. This repository
  artifact does not update the GitHub wiki; the issue/PR should carry the link.

The unit tests establish the mapped code behavior at their test boundaries. They
do not establish live deployment settings or real-user behavior.
